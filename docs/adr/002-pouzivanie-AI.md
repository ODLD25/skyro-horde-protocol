**Context**
  Talking about AI usage

**Decision**
  AIcan only help me in creating development tools that help game designers do certain stuff more easily. It can not add any new mechanics or change any already existing mechanics. It can only add new code to editor module and add variables/methods to gameplay or visual modules only if they are needed for the editor tools. 

**Consequences** 
  AI can be used to create tools for game designers. AI can not be used to create new mechanics or change already existing ones.
